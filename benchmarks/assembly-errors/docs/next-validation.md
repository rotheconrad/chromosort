# Boundary for the next validation cycle

This is a prospective plan, not an executed benchmark or a new truth set.
Begin only after the repository publication checkpoint has an immutable commit
and the next bounded cycle is explicitly assigned. Existing development records
and source hashes remain unchanged. No moving-code run is implied by this plan.

Prioritize an independently constructed panel with new loci, rather than more
seeds from the same Mla/wheat windows. Before admitting a source, recover its
versioned original/corrected sequence intervals, explicit error or biological
variant, and supporting evidence. Distinguish exact historical reconstruction
from a mechanism simulation; do not fill provenance gaps with assumed labels.

Useful next contrasts are: real biological continuity versus misjoin evidence
at comparable depth; mixed contig plans containing both useful and misleading
cuts; low coverage and deliberately unavailable CIGAR; and repeat/copy cases
where mapped read names do not constitute independent molecule evidence.
Read absence must remain neutral. A whole-contig deferral can preserve biology
and miss useful correction, so both outcomes need scoring.

Freeze the new case construction, read model, parameters, software identity and
primary paired comparison before outputs are scored. Keep new evaluation truth
outside isolated curation sessions. Public development truth in this directory
cannot serve as unseen validation, and multiple scenarios from one source are
not independent genomes.

Start with a modest local panel and measured resource use. Review any expansion
to chromosome-scale simulation, HPC, paid compute or shared CI separately.
No workflow matrix, artifact upload, retained binary dataset or release job is
part of this benchmark integration.
