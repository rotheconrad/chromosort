# Code of Conduct

ChromoSort welcomes constructive participation from users, contributors, and reviewers.

## Expected Behavior

- Be respectful and professional.
- Assume good intent while asking for clarification when needed.
- Keep bug reports, reviews, and discussions focused on evidence and reproducible behavior.
- Respect privacy around unpublished datasets, sample names, and collaborator information.

## Unacceptable Behavior

Harassment, personal attacks, discriminatory language, doxxing, or sustained disruptive behavior are not acceptable in project spaces.

## Reporting

Report conduct concerns to the repository maintainer through an appropriate private channel when possible. Public GitHub Issues are best for technical bugs and feature requests, not sensitive conduct reports.

## Enforcement

Maintainers may edit, hide, or remove comments; close issues or pull requests; or restrict participation when behavior prevents constructive project work.
